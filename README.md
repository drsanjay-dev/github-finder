# github-finder
Find GitHub user profiles and repositories with stars, forks, and more. Built with HTML, CSS, and JavaScript.

A responsive web app to find any GitHub user's profile and repositories using the GitHub API.

## 🔍 Features
- Fetch GitHub user profile info
- Display repositories with stars and forks
- Responsive for mobile, tablet, and desktop
- Clean modern UI with tech branding

## 🚀 Live Demo
[Click here to try it](https://github-profile-finder-7vwy.onrender.com)

## 📦 Tech Stack
- HTML
- CSS (Responsive)
- JavaScript
- GitHub REST API
